# Contributing

## Language

Normative documentation in this repository is written in English. Translations belong in `araru-docs`.

## Change protocol

1. Explain the user problem and affected platforms.
2. Update semantic tokens or the relevant foundation before components.
3. Document anatomy, states, interaction, accessibility and responsive behavior.
4. Record breaking decisions in `CHANGELOG.md`.

Do not add framework code or extract `@araru/ui` here until the Web and Desktop implementations demonstrate a stable shared contract.
