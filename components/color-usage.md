# Color usage

| Role | Semantic token | Purpose |
| --- | --- | --- |
| Primary action | `accent` / `accent-hover` | CTA and reading progress |
| Navigation selection | `link` / `surface-raised` | Current route and tabs |
| Links | `link` / `link-hover` | Text navigation |
| Focus | `focus-ring` | Keyboard focus |
| Errors | `danger` | Error states only |

All foreground/background pairs must be checked for WCAG 2.2 AA in both themes.
