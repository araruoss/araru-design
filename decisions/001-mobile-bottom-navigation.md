# ADR 001: Mobile bottom navigation

- Status: Accepted
- Problem: Primary destinations must remain reachable without consuming the content area with a desktop sidebar.
- Decision: Mobile uses bottom navigation for Home, Library, Search and Profile; secondary destinations remain contextual.
- Reason: It preserves thumb reachability and keeps the content surface available.
- Alternatives: compressed sidebar, hamburger-only navigation.
- Platform impact: Web mobile and Android use the same destinations; Desktop keeps side navigation.
