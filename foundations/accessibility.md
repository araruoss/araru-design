# Accessibility

Target WCAG 2.2 AA. Preserve semantic headings, labelled controls, visible focus using `focus-ring` Cyan, keyboard navigation, screen-reader announcements, contrast and comfortable touch targets (44×44 CSS px minimum where practical). Validate accent foreground as Deep Navy on Yellow/Orange. Never use color alone to communicate state; pair status colors with text, icon or structural changes.

Respect `prefers-reduced-motion`, preserve focus when dialogs close, and test both Light and Dark themes at 360px, 768px and desktop widths.
