# Responsive and adaptive

Use compact, medium, expanded and wide breakpoints only when the composition changes. Desktop uses side navigation; medium uses compact navigation; mobile uses a top bar and bottom navigation. Reflow content before merely shrinking it.

Preserve a readable content width, use fluid gaps from the spacing scale, and account for platform safe areas in immersive reader and bottom navigation surfaces. Touch targets should remain at least 44×44 CSS px where practical. Orientation changes must not clip content or reset reading position.
