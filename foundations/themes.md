# Themes

The Light theme is clean tech: neutral surfaces, Deep Navy typography, Royal Blue links, Cyan focus, and restrained Yellow/Orange actions.

The Dark theme uses Deep Navy instead of pure black, with blue-toned surfaces and light text. It is a separate composition, not an inverted Light theme.

## Do / Don't

- Do keep backgrounds neutral and let book covers provide color.
- Do use Royal Blue for selected navigation and Cyan for information/focus.
- Do use Yellow with Deep Navy text for primary actions.
- Don't use orange for errors or ordinary links.
- Don't make every card or section blue.
- Don't use raw primitive values in product components.
